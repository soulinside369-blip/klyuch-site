# КЛЮЧ — сайт IT-агентства полного цикла

Одностраничный сайт-презентация: кинематографичный трейлер и три полноэкранных слайда — оффер, портфолио, контакты.

**Живая версия:** см. ссылку GitHub Pages в описании репозитория (раздел About).

## Что внутри

- **Трейлер-заставка** (~6,5 с, один раз за визит, можно пропустить): кинетическая типографика по буквам,
  склейка направлений, ключ рисуется — и экран растворяется сквозь замочную скважину.
- **Слайд 1 — оффер.** «Открываем рост / продажи / процессы / рынки», светящаяся скважина, подсветка сетки курсором.
- **Слайд 2 — портфолио.** Вход «сквозь скважину» (CSS mask); раскрывающиеся панели кейсов.
- **Слайд 3 — контакты.** Шторка, крупная ссылка на Telegram, форма из двух полей.
- Листание как в презентации: колесо, стрелки, свайп. Если слайд не помещается в экран — обычная прокрутка.
- Уважает настройку «уменьшить движение»: анимации отключаются.

## Стек

[Astro 5](https://astro.build) (статический HTML, без JS-фреймворков), чистый CSS и ~250 строк JS.
Шрифты Unbounded, Manrope, JetBrains Mono — локально через @fontsource. Заявки — `public/api/send.php` → Telegram.

## Запуск

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # готовый сайт в dist/
```

Весь контент — в `src/data/site.ts`.

## Публикация

- **GitHub Pages:** автоматически при пуше в `main` (`.github/workflows/pages.yml`). На Pages форма заявки не работает — там нет PHP.
- **Свой хостинг с PHP:** собрать с `SITE_URL=https://домен.ru`, залить `dist/`, на сервере скопировать
  `api/config.example.php` → `api/config.php` и вписать токен Telegram-бота.
